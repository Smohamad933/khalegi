# بروشور الکترونیک کنسرت — ارکستر سازهای ایرانی خالقی

وب‌سایت تک‌صفحه‌ای «بروشور آنلاین کنسرت» به همراه **پنل مدیریت محتوا**، با PHP (بدون فریم‌ورک)، HTML، CSS و JavaScript خالص. دیتابیس روی **SQLite** است و هیچ وابستگی خارجی (Composer / npm) ندارد.

## امکانات

### سایت (بازدیدکننده)
- سرصفحه با هویت بصری پوستر: المان خطی تئاتر، پرنده‌های فیروزه‌ای، لوگوتایپ خوشنویسی + عنوان، رهبر، خواننده، تاریخ، ساعت، مکان و دکمه‌ی بلیت (در صورت آپلود عکس پس‌زمینه، همان جایگزین می‌شود)
- نمایش تصویر کامل پوستر در بخش «درباره‌ی اجرا» (با لایت‌باکس)
- منوی چسبان بخش‌ها: **قطعات موسیقی / اعضای ارکستر / عوامل اجرایی / گالری تصاویر**
- قطعات با آهنگساز، شاعر، تنظیم، متن ترانه (بازشونده)، پخش‌کننده‌ی صوتی و دانلود
- اعضای ارکستر به تفکیک گروه ساز (کارت‌های تذهیب‌دار) و عوامل اجرایی به‌صورت فهرست
- گالری متحرک + لایت‌باکس
- پالت رنگی پوستر (کرم / قرمز خطی / نارنجی عنوان / فیروزه‌ای) — همگی از پنل قابل تغییر
- کاملاً واکنش‌گرا، راست‌چین، اعداد فارسی؛ فونت پیش‌فرض وزیرمتن (لوکال) و **فونت اختصاصی قابل آپلود از پنل**

### پنل مدیریت (`/admin`)
- **اطلاعات کنسرت**: عنوان‌ها، تاریخ/مکان، یادواره/بزرگداشت، پوستر، لوگوتایپ، المان تئاتر، پرنده‌ها، لوگو، رنگ‌ها، متن معرفی، شبکه‌های اجتماعی، روشن/خاموش کردن بخش‌ها
- **فونت سایت**: آپلود فایل‌های فونت (woff2/woff/ttf/otf، چند وزن) با نام خانواده‌ی دلخواه (پیش‌فرض `abar`)؛ بلافاصله کل سایت و پنل با آن نمایش داده می‌شود
- **اعضای ارکستر** و **عوامل اجرایی**: افزودن/ویرایش/حذف گروه‌ها و اعضا، عکس برای هر عضو، افزودن چند نفر هم‌زمان، **مرتب‌سازی با کشیدن و رها کردن**
- **قطعات**: اطلاعات کامل، متن، آپلود mp3 یا لینک، لینک ویدیو، مرتب‌سازی
- **گالری**: آپلود چندتایی، توضیح تصویر، مرتب‌سازی
- **حساب کاربری**: تغییر نام کاربری و رمز عبور
- امنیت: رمز هش‌شده، توکن CSRF روی همه‌ی فرم‌ها، بررسی نوع فایل با MIME واقعی، منع اجرای PHP در پوشه‌ی آپلود

## اجرای محلی

```bash
php -S 0.0.0.0:8000 router.php
```

سپس `http://localhost:8000` را باز کنید. پنل مدیریت: `http://localhost:8000/admin/`

> ورود پیش‌فرض: **admin / admin123** — پس از اولین ورود آن را از بخش «حساب کاربری» تغییر دهید.

## استقرار روی هاست (Apache / cPanel / DirectAdmin)

1. همه‌ی فایل‌ها را در `public_html` (یا زیرپوشه‌ی دلخواه) آپلود کنید — سایت در زیرپوشه هم کار می‌کند.
2. پوشه‌های `data/` و `uploads/` باید قابل نوشتن باشند (`chmod 775` یا `777`).
3. PHP نسخه‌ی **8.1 یا بالاتر** با افزونه‌های `pdo_sqlite`، `mbstring`، `fileinfo` (در اکثر هاست‌ها فعال است).
4. با اولین بازدید، دیتابیس و داده‌ی نمونه به‌صورت خودکار ساخته می‌شود.
5. فایل‌های `.htaccess` دسترسی مستقیم به `app/` و `data/` را می‌بندند.

برای Nginx معادل این قوانین را اضافه کنید:

```nginx
location ~ ^/(app|data)/ { deny all; }
location ~* ^/uploads/.*\.php$ { deny all; }
```

## ساختار پروژه

```
index.php              صفحه‌ی اصلی بروشور
fonts.css.php          تولید خودکار @font-face از فونت‌های آپلودشده + متغیر --font
router.php             روتر سرور داخلی PHP (فقط برای توسعه)
app/
  config.php           تنظیمات (مسیر دیتابیس، آپلود، کاربر پیش‌فرض)
  bootstrap.php        راه‌اندازی
  helpers.php          توابع کمکی (escape، آپلود، CSRF، ...)
  db.php               اتصال SQLite + ساخت جداول
  seed.php             داده‌ی نمونه‌ی اولیه
  auth.php             ورود/خروج مدیر
  views/public/        قالب صفحه‌ی اصلی + اسپرایت تذهیب‌ها (SVG)
admin/                 صفحات پنل مدیریت (fonts.php = مدیریت فونت)
assets/
  css/  js/  fonts/  vendor/ (SortableJS)
  img/                 المان‌های پیش‌فرض: theatre.svg، logotype.png، bird-left/right.svg، عکس‌های نمونه
data/                  دیتابیس SQLite (خودکار)
uploads/               فایل‌های آپلودشده
```

## جایگزینی هویت بصری

همه‌ی المان‌های گرافیکی از پنل → «اطلاعات کنسرت» → بخش **تصاویر** قابل جایگزینی‌اند (نیازی به دست‌زدن به کد نیست):

| جایگاه | کلید تنظیمات | فایل پیش‌فرض | توضیح |
|---|---|---|---|
| پوستر کامل | `poster` | — | با چیدمان «خودکار» به‌محض آپلود، خودِ پوستر در سرصفحه (پرنده‌ها دو طرفش) نمایش داده می‌شود؛ در چیدمان «ترکیب المان‌ها» کنار متن معرفی می‌رود — همیشه با لایت‌باکس |
| لوگوتایپ (خوشنویسی) | `logotype` | `assets/img/logotype.png` | زیر نام رهبر/خواننده در سرصفحه و در پاورقی — PNG شفاف |
| المان خطی تئاتر | `theatre_art` | `assets/img/theatre.svg` | پس‌زمینه‌ی سرصفحه — SVG یا PNG شفاف |
| پرنده‌ی چپ / راست | `bird_left` / `bird_right` | `assets/img/bird-*.svg` | دو طرف تایپوگرافی سرصفحه، کنار عنوان بخش‌ها و در پاورقی |
| عکس پس‌زمینه‌ی سرصفحه | `hero_desktop` / `hero_mobile` | — | اختیاری؛ اگر پر شود جایگزین المان تئاتر می‌شود |
| لوگو / نشان | `logo` | — | اختیاری |

می‌توانید به‌جای آپلود، فایل‌های پیش‌فرض داخل `assets/img/` را با همان نام بازنویسی کنید.

### چیدمان سرصفحه (`hero_mode`)
در همان صفحه‌ی تنظیمات:
- **خودکار** (پیش‌فرض): اگر پوستر آپلود شده باشد → حالت «پوستر»، وگرنه «ترکیب المان‌ها»
- **پوستر**: خودِ تصویر پوستر مثل سایت نمونه، با پرنده‌ها در دو طرف و المان تئاتر کم‌رنگ در پس‌زمینه (نسخه‌ی موبایل پوستر را می‌توانید در `hero_mobile` بگذارید)
- **ترکیب المان‌ها**: المان تئاتر + عنوان نارنجی + رهبر/خواننده + لوگوتایپ + پرنده‌ها
- **عکس پس‌زمینه**: عکس تمام‌صفحه (`hero_desktop`/`hero_mobile`) و متن روی آن

### رنگ‌ها
از همان صفحه: زمینه (`color_bg`)، نارنجی عنوان (`color_accent`)، فیروزه‌ای تذهیب (`color_teal`)، قرمز خطوط (`color_line`) و طلایی (`color_gold`). این‌ها به متغیرهای CSS `--bg / --accent / --teal / --line / --gold` در `assets/css/site.css` تزریق می‌شوند.

### فونت اختصاصی (مثلاً «abar»)
1. پنل → **فونت سایت** → فایل‌های فونت را (ترجیحاً `woff2`، یک فایل برای هر وزن یا یک فایل Variable؛ فایل ZIP هم پذیرفته می‌شود) آپلود کنید؛ نام خانواده را `abar` بگذارید (پیش‌فرض همین است). وزن هر فایل از نام آن (Regular/Bold/…) حدس زده می‌شود و در فهرست پایین صفحه قابل اصلاح است.
2. `fonts.css.php` به‌صورت خودکار برای هر فایل یک `@font-face { font-family:'abar'; ... }` می‌سازد و `--font: 'abar','Vazirmatn',…` را تنظیم می‌کند.
3. `body` سایت و پنل از `font-family: var(--font)` استفاده می‌کنند، بنابراین بدون تغییر کد فونت عوض می‌شود. تا زمانی که فونتی آپلود نشده، مرورگر خودبه‌خود به وزیرمتن برمی‌گردد.

تذهیب‌های SVG (گوشه‌ها، بال عنوان‌ها، جداکننده‌ها) در `app/views/public/ornaments.php` قرار دارند و رنگشان از `currentColor` (فیروزه‌ای) گرفته می‌شود.
