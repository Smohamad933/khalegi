# بروشور الکترونیک کنسرت — ارکستر سازهای ایرانی خالقی

وب‌سایت تک‌صفحه‌ای «بروشور آنلاین کنسرت» به همراه **پنل مدیریت محتوا**، با PHP (بدون فریم‌ورک)، HTML، CSS و JavaScript خالص. دیتابیس روی **SQLite** است و هیچ وابستگی خارجی (Composer / npm) ندارد.

## امکانات

### سایت (بازدیدکننده)
- پوستر تمام‌صفحه (نسخه‌ی جداگانه برای دسکتاپ و موبایل) + عنوان، رهبر، خواننده، تاریخ، ساعت، مکان و دکمه‌ی بلیت
- منوی چسبان بخش‌ها: **قطعات موسیقی / اعضای ارکستر / عوامل اجرایی / گالری تصاویر**
- قطعات با آهنگساز، شاعر، تنظیم، متن ترانه (بازشونده)، پخش‌کننده‌ی صوتی و دانلود
- اعضای ارکستر به تفکیک گروه ساز (کارت‌های تذهیب‌دار) و عوامل اجرایی به‌صورت فهرست
- گالری متحرک + لایت‌باکس
- کاملاً واکنش‌گرا، راست‌چین، فونت وزیرمتن و گلزار (لوکال)، اعداد فارسی

### پنل مدیریت (`/admin`)
- **اطلاعات کنسرت**: عنوان‌ها، تاریخ/مکان، پوسترها، لوگو، رنگ‌ها، متن معرفی، شبکه‌های اجتماعی، روشن/خاموش کردن بخش‌ها
- **اعضای ارکستر** و **عوامل اجرایی**: افزودن/ویرایش/حذف گروه‌ها و اعضا، عکس برای هر عضو، افزودن چند نفر هم‌زمان، **مرتب‌سازی با کشیدن و رها کردن**
- **قطعات**: اطلاعات کامل، متن، آپلود mp3 یا لینک، لینک ویدیو، مرتب‌سازی
- **گالری**: آپلود چندتایی، توضیح تصویر، مرتب‌سازی
- **حساب کاربری**: تغییر نام کاربری و رمز عبور
- امنیت: رمز هش‌شده، توکن CSRF روی همه‌ی فرم‌ها، بررسی نوع فایل با MIME واقعی، منع اجرای PHP در پوشه‌ی آپلود

## اجرای محلی

```bash
php -S 0.0.0.0:8000 router.php
```

سپس `http://localhost:8000` را باز کنید. پنل مدیریت: `http://localhost:8000/admin/`

> ورود پیش‌فرض: **admin / admin123** — پس از اولین ورود آن را از بخش «حساب کاربری» تغییر دهید.

## استقرار روی هاست (Apache / cPanel / DirectAdmin)

1. همه‌ی فایل‌ها را در `public_html` (یا زیرپوشه‌ی دلخواه) آپلود کنید — سایت در زیرپوشه هم کار می‌کند.
2. پوشه‌های `data/` و `uploads/` باید قابل نوشتن باشند (`chmod 775` یا `777`).
3. PHP نسخه‌ی **8.1 یا بالاتر** با افزونه‌های `pdo_sqlite`، `mbstring`، `fileinfo` (در اکثر هاست‌ها فعال است).
4. با اولین بازدید، دیتابیس و داده‌ی نمونه به‌صورت خودکار ساخته می‌شود.
5. فایل‌های `.htaccess` دسترسی مستقیم به `app/` و `data/` را می‌بندند.

برای Nginx معادل این قوانین را اضافه کنید:

```nginx
location ~ ^/(app|data)/ { deny all; }
location ~* ^/uploads/.*\.php$ { deny all; }
```

## ساختار پروژه

```
index.php              صفحه‌ی اصلی بروشور
router.php             روتر سرور داخلی PHP (فقط برای توسعه)
app/
  config.php           تنظیمات (مسیر دیتابیس، آپلود، کاربر پیش‌فرض)
  bootstrap.php        راه‌اندازی
  helpers.php          توابع کمکی (escape، آپلود، CSRF، ...)
  db.php               اتصال SQLite + ساخت جداول
  seed.php             داده‌ی نمونه‌ی اولیه
  auth.php             ورود/خروج مدیر
  views/public/        قالب صفحه‌ی اصلی + اسپرایت تذهیب‌ها (SVG)
admin/                 صفحات پنل مدیریت
assets/
  css/  js/  fonts/  img/  vendor/ (SortableJS)
data/                  دیتابیس SQLite (خودکار)
uploads/               فایل‌های آپلودشده
```

## جایگزینی هویت بصری

- پوستر و لوگو را از پنل → «اطلاعات کنسرت» آپلود کنید.
- رنگ زمینه و رنگ طلایی از همان بخش قابل تغییر است.
- تذهیب‌های SVG در `app/views/public/ornaments.php` قرار دارند و می‌توانید آن‌ها را با المان‌های طراحی اختصاصی جایگزین کنید.
- عکس‌های فعلی در `assets/img/` صرفاً **نمونه** هستند.
